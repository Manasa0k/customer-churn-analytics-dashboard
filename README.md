# Customer Churn & Sales Analytics Dashboard

## Project Overview

This project analyzes customer purchasing behavior and churn risk using e-commerce transaction data.

The dashboard helps businesses identify high-risk customers and improve retention strategies.

## Key Metrics

* Total Customers
* Total Revenue
* Average Order Value
* Churn Rate

## Visualizations

* Customers by Risk Level
* Monthly Revenue Trend
* Top 10 Products by Revenue
* Revenue by Country
* Customer Behavior Analysis
* Churn Distribution

## Key Insights

* 33% of customers show churn risk
* High-frequency customers contribute most revenue
* United Kingdom generates the highest sales

## Tools Used

* Python
* Pandas
* Data Visualization
* Dashboard Analytics
